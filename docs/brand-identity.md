## 設計概念

**雲端城市羅盤**：把雲端服務、城市資料與政策方向整合成同一個圖形。

- **雲形外框**：專案建構於 AWS 雲端架構，承載資料、分析與服務。
- **城市輪廓**：以新北市及各行政區為政策分析場域。
- **向上羅盤**：從可靠資料找出青年發展與公共政策的方向。
- **橘色與深藍**：呼應 AWS 雲端科技意象，同時保有新北青策自己的圖形識別。

此圖形是專案自己的 Logo，不是 AWS 官方標誌或新北市政府徽章。

## 素材與使用方式

| 項目 | 說明 |
|---|---|
| 主圖檔 | [`frontend/public/youth-compass-logo.png`](../frontend/public/youth-compass-logo.png) |
| 格式 | 1254 × 1254 PNG，含透明背景 |
| 目前用途 | React 頁首、瀏覽器圖示、Apple touch icon、專案 README |
| 字標 | 中文「新北青策」及介面副標由網頁文字呈現，支援語系切換 |
| 設計色彩方向 | 深藍 `#232F3E`、橘色 `#FF9900`；生成的 PNG 帶有細微色階，這兩色是後續延伸設計的參考值 |

使用時維持正方形比例及透明留白，避免拉伸或任意裁切。建議頁首圖示至少 44 px、README 至少 120 px。深色背景可搭配淺色底板，維持深藍外框的辨識度。若要進行大型印刷，應另外製作向量版本；目前交付素材是 PNG。

## 製作紀錄

使用內建 **image_gen** 工具產生並修整。提示方向：為 AWS 智慧城市青年政策助理設計原創圖形；整合雲形、簡化城市輪廓與向上羅盤；橘色與深藍；透明背景；不加入文字、官方 AWS 字樣或政府徽章。

既有 `ntpc-logo.png` 保留作為原始素材，新版前端改用本專案 Logo。
