# 人口年齡分配

來源：[新北市政府資料開放平臺](https://data.ntpc.gov.tw/datasets/387f4683-a92e-4884-a548-268d2f77d31e)，新北市政府主計處。

- 觀測期間：2006–2024；共 114 列。
- 範圍：全市各性別人口中的年齡結構百分比；15–64歲是青壯年，不能當成18–35歲青年占比。未擷取平均壽命欄。
- 單位：%；不可跨性別、年齡組或年度加總。
- 授權：政府資料開放授權條款－第1版。
- 擷取時間、原始快照、欄位對應與 SHA-256 見 `provenance.json`。
