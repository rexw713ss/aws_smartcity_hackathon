# 勞動力參與率

來源：[新北市政府資料開放平臺](https://data.ntpc.gov.tw/datasets/34ab136e-9296-4083-952a-4ee76394fcb0)，新北市政府主計處。

- 觀測期間：2007–2024；共 144 列。
- 範圍：全市年齡組與性別；25–44歲等組別涵蓋非青年人口，不能視為18–35歲專屬參與率。
- 單位：%；不可跨性別、年齡組或年度加總。
- 授權：政府資料開放授權條款－第1版。
