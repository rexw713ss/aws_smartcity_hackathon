# 教育程度－15歲以上識字率

來源：[新北市政府資料開放平臺](https://data.ntpc.gov.tw/datasets/ffef3ed1-867e-4013-ade0-47cfdba44b2d)，新北市政府主計處。

- 觀測期間：2006–2024；共 38 列。
- 範圍：全市15歲以上人口，依性別；沒有18–35歲或行政區細分。僅擷取識字率兩欄。
- 單位：%；不可跨性別、年齡組或年度加總。
- 授權：政府資料開放授權條款－第1版。
